# Копилот — встроенный помощник

Кнопка «Копилот» во вьювере открывает чат: вопросы о проекте, расстановка,
проверки, «покажи». Копилот работает от вашего имени и с вашими правами;
изменения он только предлагает — карточка предложения в чате, «Показать» на
плане, «Применить» в один клик.

Настройка (администратор): шапка → «Копилот» (или меню ⚙ во вьювере →
«Копилот: модель и лимиты»). Нужна внешняя модель с OpenAI-совместимым API и
вызовом функций:

| поле            | пример                                                     |
|-----------------|------------------------------------------------------------|
| адрес API       | `http://localhost:11434/v1` (Ollama), `https://openrouter.ai/api/v1` |
| API-ключ        | ключ провайдера; локальным моделям обычно не нужен        |
| модель          | имя у провайдера; «Проверить» покажет доступные            |
| запросов в день | лимит на пользователя (0 — без лимита)                     |

Модели нужно окно контекста от 32 тыс. токенов (инструкции и описания
инструментов — около 9 тыс.). Ollama по умолчанию даёт 4 тыс.: задайте
`OLLAMA_CONTEXT_LENGTH=32768` или больше. Крупные модели на процессоре без
видеокарты отвечают минутами.

## Что копилот умеет

| инструмент        | что делает                                                          |
|-------------------|---------------------------------------------------------------------|
| `project_overview`| проект, чертежи с этажами, слои (и группы вариантов) с числом объектов |
| `list_rooms`      | помещения: id, этаж, название, тип, площадь, центр, габарит, контур |
| `layer_kinds`, `search_catalog` | типы слоёв и правила; поиск по каталогу              |
| `query_objects`, `get_object` | объекты по чертежу, слою, этажу, помещению, позиции, прямоугольнику |
| `report`, `recent_changes` | спецификация, проверка пожарки; журнал изменений         |
| `check_project`   | сводная проверка: пожарка, предметы в проходах / на перегородках / друг на друге / за стенами, пересечения потоков и запретные зоны, обзор камер, Wi-Fi, пустые помещения |
| `place_in_room`, `place_row` | места для предметов в помещении (у стен, в центре, по углам, сеткой; ряд) с учётом дверей и зон обслуживания |
| `place_in_rooms`  | то же сразу по многим помещениям (этаж, тип, список) — одно предложение |
| `place_detectors` | пожарные извещатели туда, где их меньше нормы по площади            |
| `plan_route`      | маршрут людей через остановки — по коридорам, через двери, по лестницам и лифтам; длина, время, конфликты потоков |
| `camera_coverage` | доля площади помещений, видимая камерами (приближённо)             |
| `compare_variants`| разница двух вариантов слоя: объекты и спецификация                 |
| `propose_changes`, `proposal_status` | предложить изменения объектов и слоёв (новый слой, вариант, переименование, удаление); узнать решение |
| `list_comments`, `add_comment` | комментарии на модели; оставить свой (сразу, только редакторам) |
| `get_ui_context`, `show_in_viewer` | что открыто у пользователя; показать место, перелететь, обвести |

Изменения копилот только предлагает (пользователям с правом редактирования);
применяет их человек — в чате или на панели «Предложения копилота». В журнале:
«логин · Копилот» и «… · по предложению копилота».

## Устройство

- `backend/dwg3d/copilot.py` — настройки, чат, обращение к модели
  (`/chat/completions`, поток), цикл с инструментами, лимиты.
- `backend/dwg3d/agent_tools.py` — инструменты. Они зарегистрированы во
  встроенном реестре библиотеки `mcp` (JSON-схемы и проверка аргументов);
  наружу по HTTP не публикуются — внешних агентов и токенов нет.
- Копилот вызывает инструменты от имени вошедшего пользователя, с его правами
  в проекте (не выше «просмотра» — предложения правами не требуют записи).
