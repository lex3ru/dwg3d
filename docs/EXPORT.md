# Формат полной выгрузки

Полная выгрузка (ТЗ 7.4, 8.7 п. 3) — архив ZIP, который можно хранить отдельно и прочитать
без системы: обычные таблицы Excel и файлы. Делает её администратор в «Отчётах» →
«Полная выгрузка»: по одному зданию или по всем сразу. Собирается в фоне; на стенде объёмов
8.1 одно здание — около 2 с, все 20 зданий — около минуты.

Архив хранится в системе срок из «Настроек» (по умолчанию 30 дней) и в резервные копии не
входит. Нужен надолго — скачайте его и сохраните отдельно (R-027, ADR-0024).

## Состав архива

Выгрузка одного здания — файлы в корне архива; всех зданий — по папке на здание
(`<Название здания>/…`), а каталог и 3D-модели — один раз в корне.

```
README.txt                   когда и что выгружено
Помещения.xlsx               этажи и помещения
Расстановка.xlsx             предметы на плане
Имущество.xlsx               инвентарные единицы
Характеристики.xlsx          значения характеристик у каждой вещи
Остатки.xlsx                 количественный учёт по местам
Документы.xlsx               строки проведённых документов
История.xlsx                 журнал изменений
Каталог.xlsx                 каталог целиком (в корне архива)
файлы/чертежи/               загруженные DWG и DXF
файлы/подложки/              подложки планов (PDF, картинки)
файлы/имущество/             фото и документы вещей
файлы/документы/             сканы и файлы документов движения
файлы/3D-модели/             3D-модели типов каталога (GLB)
```

Имя файла в папке `файлы/` — «подпись — исходное имя»: для чертежа подпись — название
чертежа, для подложки — этаж, для вещи — её инвентарный номер (у фото — «номер фото»), для
документа — его номер («Приход ПР-00012»), для 3D-модели — тип каталога. Один и тот же файл
кладётся один раз.

## Таблицы

В каждой таблице одна вкладка. Первая строка — заголовок («Здание — помещения»), вторая
пустая, третья — названия столбцов, дальше данные. Даты — даты Excel, деньги — в рублях
числом, размеры — в миллиметрах.

### Помещения.xlsx

| Столбец | Что |
|---|---|
| Этаж | название этажа |
| Номер | номер помещения |
| Название | название помещения |
| Назначение | назначение из справочника (норма освещённости — в «Каталог.xlsx», лист «Назначения помещений») |
| Площадь, м² | площадь по плану |

### Расстановка.xlsx

| Столбец | Что |
|---|---|
| Этаж, Помещение | где стоит предмет; «вне помещений», если не внутри контура |
| Тип, Модель | тип и модель каталога |
| X, мм; Y, мм | координаты центра на плане этажа (начало координат — как в редакторе) |
| Поворот, ° | угол поворота, как в свойствах предмета в редакторе |
| Высота, мм | высота установки над полом (настенные, потолочные) |
| Подпись | подпись предмета на плане |
| Инв. № | номер связанной инвентарной единицы, если связан |

### Имущество.xlsx

Инвентарный номер, наименование, модель, серийный номер, место («Этаж › Помещение» или
«Склад «…» › Ячейка»), состояние, ответственный, подразделение, дата ввода, цена, остаточная
стоимость на день выгрузки, срок службы в месяцах. Списанные единицы — тоже, с состоянием
«списана».

### Характеристики.xlsx

| Столбец | Что |
|---|---|
| Инв. № | номер единицы |
| Наименование | тип |
| Характеристика | название характеристики «у каждой вещи» |
| Значение | как в карточке: число с единицей, дата, вариант, да/нет |

Характеристики, общие для типа или модели, — в «Каталог.xlsx».

### Остатки.xlsx

| Столбец | Что |
|---|---|
| Место | помещение или склад |
| Тип, Модель | что лежит |
| Ед. | единица измерения |
| Количество | остаток |
| Сумма | по средней цене |

### Документы.xlsx

Строки проведённых и отменённых документов, касающихся здания (его помещений, складов или
единиц), по порядку дат.

| Столбец | Что |
|---|---|
| Дата | дата документа |
| Документ | вид и номер; «(отменён)» — если документ отменён обратным |
| Что | тип и инвентарный номер или тип количественного учёта |
| Кол-во, Ед. | 1 для единицы, иначе количество |
| Откуда, Куда | места |
| Сумма | цена × количество |
| Примечание | причина (списание, ремонт) или примечание строки |

### История.xlsx

Журнал изменений здания, этажей и помещений: «Когда», «Кто», «Что» (текстом), «Было» и
«Стало» — значения полей до и после в виде текста JSON (до 3000 знаков на ячейку).

### Каталог.xlsx

Тот же файл, что «Каталог» → «Выгрузить в Excel»: листы «Как читать», «Слои», «Наборы
характеристик», «Типы», «Модели», «Назначения помещений». Его можно загрузить обратно в
систему («Загрузить из Excel» в каталоге).

## Чего в выгрузке нет

- Учётных записей и паролей, ссылок на просмотр, настроек системы.
- Проектов (они не меняют расстановку, пока не применены).
- Геометрии планов (стены, проёмы) — она в резервной копии; план этажа в виде чертежа
  выгружается отдельно: редактор → печать → DXF или PDF, или «Отчёты» → «План этажа с
  расстановкой по слоям».

Полное восстановление системы — из резервной копии ([INSTALL.md](INSTALL.md)), а не из
выгрузки.

## Перенос здания — другой файл

Полная выгрузка — чтобы читать без системы. Чтобы **загрузить здание в другую установку**,
есть пакет переноса: «Здания» → карточка здания → «Выгрузить для переноса». Это тоже ZIP, но
для программы: `manifest.json` (вид `planuchet-building`, версия, откуда, когда, сколько
чего, список файлов), `catalog.json` (слои, наборы характеристик, типы, модели и назначения,
которыми пользуется здание), `building.json` (этажи с планами и лифты), `items.json`
(предметы расстановки), `inventory.json` (склады здания, метки дверей, инвентарные единицы,
остатки) и `files/` (подложки, 3D-модели, фото и файлы единиц). Ключи в нём — id на исходной
установке. Загружается на другой: «Здания» → «Загрузить из файла» — с проверкой перед
загрузкой.
