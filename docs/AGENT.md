# ИИ-агенты: подключение по MCP

Агент (Claude Code, Claude Desktop, любой MCP-клиент) работает с проектом через
MCP-сервер программы: `https://<сайт>/api/mcp` (Streamable HTTP). Доступ — по
токену агента; план развития — в [AGENT_PLAN.md](AGENT_PLAN.md).

## Токен

Проект → «ИИ-агенты» → «Токен». Токен действует только в этом проекте, от имени
создавшего, с его правами, но не выше режима:

| режим         | что может агент                                                    |
|---------------|--------------------------------------------------------------------|
| только чтение | читать проект                                                      |
| предложения   | пока то же, что чтение                                             |
| изменение     | как редактор: объекты, метки, создание и изменение слоёв (через HTTP API; инструменты MCP для записи — этап 3) |

Участники, ссылки, токены, удаление слоёв, чертежей и проекта, ревизии DWG,
каталог, блокировка слоёв агенту недоступны ни в каком режиме. Изменения агента
в журнале подписаны «логин · агент «название токена»». Токен показывается один
раз; отозвать — там же.

## Claude Code

После создания токена страница показывает готовую команду:

```bash
claude mcp add --transport http dwg3d https://<сайт>/api/mcp --header "Authorization: Bearer dwg3d_…"
```

Дальше — обычные вопросы: «сколько камер на втором этаже корпуса А», «в каких
кабинетах нет кушетки», «покажи последние изменения».

## Инструменты (только чтение)

| инструмент        | что возвращает                                                       |
|-------------------|----------------------------------------------------------------------|
| `project_overview`| проект, роль и режим токена, чертежи с этажами, слои с числом объектов |
| `list_rooms`      | помещения чертежа: id, этаж, название, тип, площадь, центр, габарит; по запросу — контур |
| `layer_kinds`     | типы слоёв, допустимая геометрия и категории, правила маршрутов и зон |
| `search_catalog`  | категории каталога; позиции по названию, id, артикулу, тегам          |
| `query_objects`   | объекты по чертежу, слою, этажу, помещению, позиции каталога, прямоугольнику |
| `get_object`      | объект целиком, с версией строки                                      |
| `report`          | спецификация по этажам / по помещениям, проверки (пожарные извещатели) |
| `recent_changes`  | журнал изменений проекта                                              |

Координаты — метры в плане этажа, округлены до сантиметра. Этаж задаётся id
внутри чертежа (`c0`, `c1`…), помещение — числовым id.

## Устройство

- `backend/dwg3d/agent_mcp.py` — сервер (SDK `mcp` 2.x, `MCPServer`), без
  состояния: любой процесс API отвечает на любой запрос, ответы — JSON.
- Каждый вызов инструмента заново проверяет токен из заголовка и выполняется
  как его пользователь через те же функции и проверки прав, что и HTTP API.
- `/api/mcp` без токена агента — 401 (сессия браузера не подходит).
- Проверка вручную: `uv run pytest tests/test_agent_mcp.py`; локально с
  выключенным входом — конфигурация запуска `api-noauth` (порт 8766).
