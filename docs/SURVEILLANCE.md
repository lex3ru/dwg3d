# Подключение физической камеры

В меню есть раздел «Видеонаблюдение» → «Видеокамеры». Выберите здание: все камеры
показаны сеткой по четыре с автоматическим просмотром подключённых. Есть пауза,
переключение страниц, открытие настроек и переход к предмету на плане.

1. Выберите камеру в расстановке на плане. Откроется окно видеонаблюдения.
2. Администратор открывает «Настройки» и указывает адрес RTSP, например
   `rtsp://192.168.1.100:554/stream1`. Логин и пароль камеры вводятся отдельно.
3. Нажмите «Сохранить и открыть видео». Повторное открытие — кнопкой «Видео с камеры»
   в свойствах предмета.

Адрес должен быть доступен **серверу приложения**. В Docker-образ приложения добавлен
FFmpeg; для запуска сервера без Docker установите FFmpeg и обеспечьте его наличие в PATH.
Миграция 0018 применяется штатным запуском `python -m app serve`.

Просмотр: 5 кадров/с, ширина 960 пикселей, без звука и архива. При закрытии окна процесс
останавливается; раз в минуту переподключение повторно проверяет права на здание.
До четырёх одновременных просмотров на процесс приложения. При ошибке есть кнопка
переподключения. Сохранение адреса само по себе не подтверждает доступность камеры.

Просмотр доступен авторизованным пользователям выданного здания, настройка — только
администратору. Гости и проектные варианты не открывают физические камеры.
Пустой пароль в форме сохраняет предыдущий, отдельный флажок удаляет его.
Удаление предмета с плана удаляет подключение, отмена удаления не восстанавливает пароль.

Пароли зашифрованы. Файл `APP_DATA_DIR/surveillance.key` необходим при восстановлении
БД; штатная резервная копия всего APP_DATA_DIR включает этот файл. Не добавляйте ключ
в Git и не передавайте его с выгрузками здания. Настройки подключения не входят в
перенос здания. Прежний эксперимент с серверным JSON-файлом больше не используется.

Frigate запущен отдельным стендом: [инструкция](../deploy/frigate/README.md).
Пока приложение не использует его API; подсчёт посетителей и другие задачи аналитики
не реализованы. Для пилота нужен адрес реальной камеры, проверка видео и ракурса.
