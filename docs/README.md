# Документация проекта

Документация живёт рядом с кодом и меняется в том же MR, что и код. Если поведение поменялось, а документ нет — MR не готов.

| Что | Где | Кто обновляет |
| --- | --- | --- |
| Карта проекта для людей и агентов | [`../AGENTS.md`](../AGENTS.md) | Вручную, через MR |
| Архитектура: компоненты, связи, данные | [`architecture.md`](architecture.md) | Навык `finish`, когда меняется архитектура |
| Термины предметной области | [`glossary.md`](glossary.md) | Кто встретил новый термин |
| Решения и их причины (ADR) | [`decisions/`](decisions/README.md) | Навык `adr` |
| Задачи: план, журнал, передача | [`tasks/`](tasks/README.md) | Навыки `pickup`, `handoff`, `finish` |

Принцип: всё, что нужно следующему человеку или агенту, лежит здесь. Чаты, личная память агентов и устные договорённости не считаются.
