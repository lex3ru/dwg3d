# Этап 7. Интерфейс

`web/src` (16,8 тыс. строк): клиент API, каркас, редактор и 3D, инвентаризация, общие
состояния ошибок. Проверка типов, линтер и сборка — этап 0; доступность и телефон — e2e
(`a11y.spec.ts`, проекты «телефон»), проходят.

## Итог

Интерфейс устроен аккуратно: ошибки сервера показываются человеческим языком, правки
расстановки сверяют версии, черновик плана переживает закрытие вкладки, 3D освобождает
видеопамять. Новые находки — незначительные: мерцание стен в 3D (замечание ручного прогона),
потеря отметок офлайн-очереди при 502/401, указания по правке у «просмотра», белый экран при
сбое отрисовки.

## Что проверено

| Тема | Вывод |
|---|---|
| Клиент API (`lib/api.ts`) | Заголовок `X-Requested-With`; ошибка сервера → его сообщение; сеть → «Нет связи…»; 401 → общее событие выхода |
| Одновременная правка | Редактор шлёт версии предметов, при конфликте перечитывает этаж; план — `plan_version`, черновик при восстановлении сверяет версию |
| 3D | Геометрия стен — параллелепипеды с продлением в узлах → мерцание (R-029); геометрия освобождается при пересборке (`View3D.tsx:142`, `calc.tsx:257`) |
| Офлайн-очередь (С18) | Порядок сохраняется, повтор безвреден (сервер); при ответе с ошибкой отметка выбрасывается (R-030) |
| «Просмотр» в редакторе | Указания по правке и серые поля (R-031); права на сервере — этап 2 |
| Ошибки отрисовки | Error Boundary нет (R-032) |
| Объём сборки | Основной пакет 888 КБ (260 КБ gzip), 3D и PDF — отдельными пакетами по требованию |
| Окно применения проекта | R-007 (этап 0) |
| Адрес меток | R-016 (этап 2) |

## Ручной прогон

Замечание 1 (Б1, мерцание стен в 3D) → R-029. Строка 2 в отчёте — повтор строки 1.
