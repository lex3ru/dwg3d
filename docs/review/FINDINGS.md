## Подробно

### R-001 · З · Номер без указания забирает номер, явно указанный ниже в том же документе

- **Где:** `server/app/modules/inventory/units.py:450` (`Numbers.issue`), вызов —
  `documents.py:431`; предварительная проверка — `excel.py:381-391`.
- **Что не так:** `Numbers` знает только номера из базы и уже обработанные строки. Строка
  без номера выше строки с явным номером получает этот номер, а строка с явным номером
  потом падает «уже занят». Предварительная проверка Excel этого не видит — проверка
  проходит, загрузка отказывает.
- **Сценарий:** пустая база; Excel, где первая строка — вещь без номера, ниже — `000001` →
  проверка «ошибок нет» → «Загрузить» → «Инвентарный номер 000001 уже занят», ничего не
  загружено. Ожидается: номер без указания — следующий, не занятый ни в базе, ни в документе.
  То же для любого документа со строками с номером и без (приход, ввод остатков с плана).
- **Подтверждение:** e2e-стенд, обычный приход: строка без номера, ниже — строка с номером
  `000030` (следующий свободный) → «строка 2: Инвентарный номер 000030 уже занят»; те же
  строки в обратном порядке → проведён, `000030`, `000031` (`artifacts/stage3-r001.txt`).
- **ТЗ:** 4.6 п. 2, 7.3 п. 1 (проверка до загрузки должна показать то, что помешает загрузке).
- **Предложение:** в `Numbers` до выдачи занести в `taken` все явные номера строк документа
  (или выдавать номера вторым проходом после всех явных); тест на такой порядок строк.
- **Статус:** исправлена — [!3](https://git.mosai.pro/tristanov.ab/dwg3d/-/merge_requests/3): номера, вписанные в строки документа, резервируются до выдачи (`Numbers(reserved=…)`); проверка Excel и загрузка дают одно и то же. Тесты `test_posting.py::test_r001_*` — в документе и при загрузке Excel.

### R-002 · З · Совпадение по номеру помещения — «точно», даже если название другое

- **Где:** `server/app/modules/inventory/excel.py:331-342`.
- **Что не так:** помещение из файла сопоставляется по номеру на этаже; название при этом не
  сравнивается, результат — `exact`. На образце `docs/samples/имущество-пример.xlsx`
  «1, 101 Регистратура» → «101 Холл», «1, 105 Кабинет УЗИ» (аппарат за 3,15 млн) → «105
  Склад», «1, 106 Склад» (расходники) → «106 Кабинет врача».
- **Сценарий:** загрузить образец, не просматривая каждое помещение → вещи числятся не там,
  ошибок и предупреждений нет. ТЗ 4.6 п. 1 прямо говорит, что кабинеты в образце условные.
- **Подтверждение:** чтение кода; как это выглядит на экране — ручной прогон, Б4 (если реестр пуст) или этап 3.
- **Предложение:** номер совпал, название заметно другое (`similarity` ниже порога) —
  «похоже», с показом обоих названий, а не «точно».
- **Статус:** открыта

### R-051 · Н · В Windows процессы uvicorn застревают в accept — запросы висят без ответа

  `test_events::test_admin_receives_changes` в Windows падал: интервал ping 0,01 с меньше тика

  R-049 → запросы должны обслуживаться.
- **Подтверждение:** py-spy — 58 застреваний в `accept (socket.py:295)` за 25 мин прогона;

- **ТЗ:** 8.7 п. 2 (e2e), 6.1 п. 8 (изменения без перезагрузки).
