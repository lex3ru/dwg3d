# Этап 5. Связь, расчёты, проекты, отчёты

Модули `link`, `calc`, `projects`, `reports`. Модули нижних уровней (`journal`, `files`,
`system`, `access`) разобраны на этапах 1–2.

## Итог

Новых критичных и значимых дефектов нет. Модули верхнего уровня опираются на учёт и
планировку и наследуют их дефекты (R-019 — гонки, R-020 — даты, R-009 — связи в обработчике,
R-007 — окно применения проекта). Одна новая находка — R-027 (архивы выгрузок не удаляются).

## Что проверено

| Тема | Вывод |
|---|---|
| Перенос связанного предмета (С13) | «Перемещение» проводится в той же транзакции; ошибка (единица списана, другого типа, предмет вне помещений) откатывает и расстановку |
| Документ → план | Единица ушла или списана документом — её предмет снимается с плана (`units_changed`) |
| Постановка на учёт с плана | Поштучные — по строке на предмет; количеством — только недостающее до числа на плане (по типу, без моделей — та же основа, что R-021) |
| Одна единица — один предмет | `unique` на `item.unit_id` + проверка при связывании |
| Применение проекта | Одной транзакцией; столкнувшееся остаётся в проекте; выбранная единица проходит проверки связи; версия — без блокировки; по коду двойное одновременное применение упрётся в повтор первичного ключа предмета (500), без порчи — не проверялось |
| Камеры | `D = разрешение / (2·tg(угол/2)·порог)`, горизонталь с учётом высоты; ≥ 120° — угловое приближение. 2688 точек, 103°, 250 пк/м → 4,28 м — по DORI (IEC 62676-4) |
| Освещённость | `I₀ = Φ·(n+1)/(2π)` — верная нормировка `cosⁿ`; `E = I·cos θ / d²`; запас и отражения — коэффициентами (упрощение по ТЗ 4.6) |
| Ведомость стоимости | Итог на сегодня = сумма цен единиц реестра (1 316 310) + сумма остатков (34 700) = 1 351 010; число единиц совпадает |
| Права отчётов | Все маршруты отчётов, главной, выгрузок — администратор (этап 2) |
| Полная выгрузка | Фоновая задача, архив в `data/exports`, скачивает администратор; архивы не удаляются (R-027) |
