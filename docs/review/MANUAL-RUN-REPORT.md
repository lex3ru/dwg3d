| 3 | Б4, загрузка из Excel | неудобно | Метки «точно», «похоже — проверьте», «не найдено» — мелким серым текстом, строки одного вида: трудно найти, что требует внимания | Метка — `11px`, без цвета и значка; вдобавок «точно» ставится при совпавшем номере и другом названии помещения | R-045, R-002 |
| 4 | Б4, приход | ошибка | Выпадающий список «Наименование» в строке документа раскрывается внутри блока строк (с прокруткой), а не поверх него | Список позиционирован внутри карточки с горизонтальной прокруткой — она его обрезает. Так же у выбора единицы | R-044 |
| 5 | Б6, применение проекта | ошибка | После подтверждения «Применить» сразу снова появляется такое же окно, но уже «добавится 0…»; итога применения не видно | Окно сбрасывает итог, когда заново загружается предпросмотр проекта. Проект при этом применён | R-007 |

| 7 | Б7, отчёты | неудобно | При раскрытии отчёта растягивается и соседний блок в той же строке — сбивает и выглядит неаккуратно | Сетка в две колонки растягивает ячейки строки по высоте | R-046 |

## Общее впечатление

Система удобная: 3D, расстановка, расчеты, поиск и доступ - без нареканий. Показывать
пользователям после исправления найденного, в первую очередь загрузки из Excel и режима
проекта.

## Итог

- Основное работает во всех блоках, кроме загрузки имущества из Excel (не удалось из-за
  невидимого списка ошибок); удобство — 4–5 из 5, проекты — 3.
- 7 замечаний: подтверждены уже найденные ревью R-029, R-007, R-002; новые — R-042, R-047 (З),
  R-043, R-044, R-045 (Н), R-046 (С).
- Самое важное: № 2 (R-047) — без исправления начальное наполнение из Excel (С10) не пройти,
  если в файле есть ошибки; № 6 (R-042) — можно незаметно править настоящую расстановку вместо
  проекта.
