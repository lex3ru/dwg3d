# Этап 4. Здание, каталог, планировка

Модули `building` (план, геометрия, перевод чертежей, печать), `catalog`, `planning`.
Проверки — на e2e-стенде и разбором чертежей в отдельных процессах; выводы —
`artifacts/stage4-*.txt`.

## Итог

- **R-009 (К) воспроизведён целиком:** повторный перевод чертежа на этаж с предметами оставляет
  стол и связанную с ним единицу в убранном помещении; тот же план, сохранённый запросом, всё
  переносит.
- **R-023 (З):** убранное помещение с имуществом — вещи остаются в архивном помещении и
  выпадают из инвентаризации этажа; окно подтверждения об этом молчит.
- **R-024 (З):** вид учёта типа меняется при существующих единицах — учёт по типу ломается.
- Проверка входа у плана и расстановки — строгая: `NaN`, бесконечность, огромные координаты,
  вложение с другого этажа отклоняются; сохранение плана защищено блокировкой этажа.

## Что проверено

| Тема | Вывод |
|---|---|
| Сохранение плана | Строка этажа `FOR UPDATE`, версия плана под блокировкой; объединение — с выбором, при переводе чертежа — первое помещение; убранные — в архив без продолжения (R-023) |
| Вход плана | `NaN`, `Infinity`, `1e300` в узлах → 422 «Проверьте поле …» (`stage4-plan-nan.txt`) |
| Расстановка | `NaN`, `Infinity`, `1e300` в координатах и угле → 400; вместилище с другого этажа → 400 (`stage4-items-fuzz.txt`) |
| Перевод чертежей | Пустой, одна линия, только текст, координаты 1e12, вырожденные и самопересекающиеся контуры, блок, вставляющий сам себя, — без ошибок; 3000 вставок блока — 48 с; 50 000 пересекающихся линий — дольше 25 мин (R-026). Сшивка стен — на `STRtree`, квадратичных проходов нет. Реальных чертежей в репозитории нет |
| Повторный перевод | Помещения узнаются по номеру — подтверждено; связи модулей в обработчике не работают (R-009) |
| 3D-модели | Сигнатура и версия проверяются; остальные ошибки разбора — 500; размножающееся дерево узлов — долгий счёт (R-025) |
| Каталог | Вид учёта меняется без проверки использования (R-024); удаление используемого типа — запрещено (подписка `on_usage`) |
| Печать плана | Экранирование подписей, номеров помещений — этап 2 |

## Ограничения

- Время перевода на реальных чертежах («Бастион», «2022-06-02», медицинский центр) не
  проверено: файлов нет в репозитории, LibreDWG на машине нет (есть в образе стенда).
- Геометрия помещений (`geometry.py`, 327 строк) и выравнивание этажей не разбирались
  построчно — покрыты тестами на 80 % и проверены e2e С1–С3.
