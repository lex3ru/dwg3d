# Ручной прогон

Цель — убедиться, что основное работает, и оценить удобство. Стенд `planuchet`
(`https://localhost`), браузер на ПК. Результаты — в [MANUAL-RUN-REPORT.md](MANUAL-RUN-REPORT.md).

В каждом блоке: шаги, что должно получиться, и вопросы для оценки удобства. Если что-то
не получается или неудобно — записать и идти дальше. Данные стенда изменятся.

Не входит: телефон и инвентаризация по QR, загрузка чертежей DWG/DXF, резервные копии —
это проверяется в автоматических этапах ревью.

## Б0. Начало

| Сделать | Должно получиться |
|---|---|
| Открыть `https://localhost`, войти администратором | главная: «Требует внимания», стоимость, последние документы |
| Слева выбрать здание «Поликлиника». Если его нет — в `deploy/`: `docker compose exec app python -m app sample polyclinic`, обновить страницу | 3 этажа |
| Меню пользователя → тёмная тема, затем обратно | всё читается в обеих |
| В любом разделе — F1 | справка этого раздела |

**Оценить:** понятно ли с первого взгляда, где что; названия пунктов меню.
