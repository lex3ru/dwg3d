# DWG3D-23: Карточка чертежа: выбор частей, этажи, ход перевода

## Цель

Подзадача DWG3D-1 (исправления по ревью), находки R-064…R-069. После перевода карточка
чертежа сама ставит части на этажи по названию, по несколько на один, и «Перевести в планы»
заменит планы этажей. Отметки новых этажей идут по порядку частей, а не по названию.
Незамкнутый план получает итог «без замечаний проверки». Не видно ожидания в очереди и
замечаний перевода, а в журнале обработчика нет записей о задачах.

## Критерии готовности

- [ ] Переведённые части и части, не похожие на этаж, по умолчанию «не переводить». Несколько
      частей на один этаж — отказ с понятной причиной. Выбор снимается и ставится для всех
      частей сразу. Названия новых этажей не повторяются (R-064).
- [ ] Отметка нового этажа считается по номеру из введённого названия (R-065).
- [ ] По итогу части видно, что план не замкнут (R-066).
- [ ] Ожидание в очереди и замечания перевода видны в карточке (R-067, R-068).
- [ ] В журнале обработчика есть начало, конец, отмена и отказ задач, нет шума сборки мусора;
      число ошибок чтения LibreDWG видно в итоге разбора (R-069).
- [ ] Сценарий каждой находки покрыт тестом, который до исправления падал; CI зелёный.
- [ ] В FINDINGS у R-064…R-069 — статус со ссылкой на MR; справка, ADMIN, ACCEPTANCE
      обновлены.

## План

<!-- Проверяемые шаги. Отмечайте выполненное, добавляйте найденное по ходу. -->

- [ ] 1. Тесты сервера, до исправления падают (`test_drawings.py`, `test_tasks.py`):
      R-064 — две части на один этаж, два новых этажа с одним названием, новый этаж с
      названием существующего — отказ 400 с названиями; R-065 — три части без подписей,
      новые «1 этаж», «3 этаж», «2 этаж» — отметки ±0, +6,600, +3,300; R-066 — наружная стена
      с разрывом 6 м — в итоге части есть концы стен без примыкания и малая доля этажа в
      помещениях; R-069 — строки журнала задачи (caplog), `gc gen2` в обработчике не INFO,
      поддельный `dwg2dxf` с ошибками в stderr — их число в `sheet`.
- [ ] 2. Сервер R-064, R-065 (`building/drawings.py`): `start_convert` отказывает в повторах
      этажей и названий; отметка нового этажа — по `captions.level` из введённого названия,
      без номера в нём — по подписи части, как сейчас.
- [ ] 3. Сервер R-066 (`drawing/convert.py`): в итоге части — число концов стен без примыкания
      (узлы одной стены) и доля очертания этажа, покрытая помещениями. Пороги «план не
      замкнут» — подобрать на тестовых чертежах (`bastion`, `extra`), чтобы годные планы не
      ругались.
- [ ] 4. Сервер R-069: в `core/tasks.py` — строка на начало, конец (за сколько), отказ
      (причина), отмену и остановку по сроку; `gc gen2` (`calc/api.py`) — INFO только в
      процессе приложения, где это прибор ADR-0010, в обработчике — DEBUG; `read.to_dxf`
      считает строки ошибок LibreDWG — в `sheet.read_errors`.
- [ ] 5. Интерфейс (`web/src/pages/Drawings.tsx`): предложение выбора — чистой функцией с
      тестом vitest (переведённые и не-этажи — «не переводить», этаж — одной части, названия
      новых без повторов); «Не переводить ничего» / «Предложить этажи»; `queued` дольше 3 с —
      «ждёт очереди: переводится другой чертёж»; замечания перевода под итогом части; «план не
      замкнут: …» вместо «без замечаний проверки»; «прочитан с ошибками: N».
- [ ] 6. e2e С1 (`stage2.spec.ts`): после перевода обе части — «не переводить»; итог части.
- [ ] 7. Справка (`help/content.ts`, `npm run admin-guide`), ACCEPTANCE (5.1.3, 6.6),
      FINDINGS R-064…R-069.
- [ ] 8. Проверки как в CI; проверка на стенде на тестовых чертежах: повторное открытие
      карточки, перевод ещё одного этажа, очередь из двух чертежей, журнал обработчика.

## Решения и находки

<!-- ГГГГ-ММ-ДД — что решили и почему; что пробовали и отвергли. Архитектурное → ADR. -->

- 2026-10-30 — незамкнутость плана (R-066) — в итоге перевода, а не в проверке
  `geometry.check`: проверка — перечень 5.1.5, и редактор показывал бы её на каждом плане с
  отдельно стоящей стеной. Схема базы не меняется: итоги и `sheet` — JSON чертежа; новые поля
  ответа и отказы 400 — дополнение, ADR не нужен.
- 2026-10-30 — предупреждение ezdxf о кэше в `HOME=/app` (R-069) — за рамками, как в DWG3D-18.
