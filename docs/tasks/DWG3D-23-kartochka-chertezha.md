# DWG3D-23: Карточка чертежа: выбор частей, этажи, ход перевода

## Цель

Подзадача DWG3D-1 (исправления по ревью), находки R-064…R-069. После перевода карточка
чертежа сама ставит части на этажи по названию, по несколько на один, и «Перевести в планы»
заменит планы этажей. Отметки новых этажей идут по порядку частей, а не по названию.
Незамкнутый план получает итог «без замечаний проверки». Не видно ожидания в очереди и
замечаний перевода, а в журнале обработчика нет записей о задачах.

## Критерии готовности

- [x] Переведённые части и части, не похожие на этаж, по умолчанию «не переводить». Несколько
      частей на один этаж — отказ с понятной причиной. Выбор снимается и ставится для всех
      частей сразу. Названия новых этажей не повторяются (R-064) — `test_r064_*`,
      `drawingParts.test.ts`, e2e С1, браузер.
- [x] Отметка нового этажа считается по номеру из введённого названия (R-065) — `test_r065_*`.
- [x] По итогу части видно, что план не замкнут (R-066) — `test_r066_*`, браузер.
- [x] Ожидание в очереди и замечания перевода видны в карточке (R-067, R-068) — `jobs.test.tsx`,
      e2e С1, браузер.
- [x] В журнале обработчика есть начало, конец, отмена и отказ задач, нет шума сборки мусора;
      число ошибок чтения LibreDWG видно в итоге разбора (R-069) — `test_r069_*`, журнал
      обработчика на стенде разработки.
- [ ] Сценарий каждой находки покрыт тестом, который до исправления падал; CI зелёный — тесты
      сервера до исправления падали (проверено); локально — ruff, pytest весь, typecheck,
      oxlint, vitest, сборка, e2e С1; CI MR — ждёт раннера.
- [x] В FINDINGS у R-064…R-069 — статус со ссылкой на MR; справка, ADMIN, ACCEPTANCE
      обновлены; ADR-0010 — уточнение о строке `gc gen2`.

## Решения и находки

<!-- ГГГГ-ММ-ДД — что решили и почему; что пробовали и отвергли. Архитектурное → ADR. -->

- 2026-10-30 — незамкнутость плана (R-066) — в итоге перевода, а не в проверке
  `geometry.check`: проверка — перечень 5.1.5, и редактор показывал бы её на каждом плане с
  отдельно стоящей стеной. Схема базы не меняется: итоги и `sheet` — JSON чертежа; новые поля
  ответа и отказы 400 — дополнение, ADR не нужен.
- 2026-10-30 — предупреждение ezdxf о кэше в `HOME=/app` (R-069) — за рамками, как в DWG3D-18.
- 2026-10-30 — R-066, порог: на четырёх тестовых чертежах (`Downloads`: «Планы, Разрезы,
  Фасады (2).dwg», «Диплом_Аквапарк_Совмеска_recover.dwg» и их DXF A/B — те же чертежи) у
  годных планов помещения покрывают 85–98 % очертания этажа, у аквапарка (оборванные стены) и
  «План 2 этажа»/подвала второго чертежа — 45–64 %. Концов стен без примыкания у всех десятки–
  сотни (10–20 % стен: мебель, стойки, ограждения) — как признак не годятся, в итоге только
  подсказкой. `closed` = доля ≥ 70 %. Стенд planuchet для калибровки не подошёл: там только
  «Поликлиника» (89 %, 0 концов).
- 2026-10-30 — R-066, тест: разрыв 6 м между концами стен на одной линии перевод закрывает сам
  (`_bridge`: проём до 7 м) — план замкнут, и находка в таком виде не воспроизводится. Тест —
  на недорисованном углу: концы не смотрят друг на друга, правое помещение открыто (53 %).
- 2026-10-30 — R-069: ошибки LibreDWG — строки, начинающиеся с «ERROR» (dwg2dxf 0.14 из образа):
  у целого DWG только «Warning», у восстановленного тестового — 509 «ERROR». Длительность
  задачи в журнале — по `started_at`/`finished_at` задачи: опрос обработчика давал у всех ~2 с.
- 2026-10-30 — R-067: «ждёт очереди» — по `created_at` задачи (как у ведомости, но без своего
  отсчёта): страница, открытая во время долгого ожидания, сразу показывает ожидание.
- 2026-10-30 — R-064: на сервере новый этаж с названием этажа здания — тоже отказ (без регистра
  и лишних пробелов): иначе в здании два «1 этаж», и не понять, какой куда переведён.

**Как проверить:**

```bash
cd server && uv run ruff check app migrations tests

cd web && npm run typecheck && npm run lint && npm test && npx vite build
```

Вручную (С1): загрузить DXF с двумя этажами → «Перевести в планы» → после перевода обе части
«не переводить», кнопка недоступна, под итогом — «Совмещён с другими этажами». Два новых этажа
с одним названием — отказ с названиями частей. При остановленном обработчике — «ждёт очереди».
Часть с недорисованным углом стен — «план не замкнут: помещения — 53 % этажа…».

**За рамками:** что станет с расстановкой при переводе поверх этажа (R-064 «не проверено»);
предупреждение ezdxf о кэше в `HOME=/app` (DWG3D-18); разрыв в наружной стене до 7 м между
концами на одной линии перевод по-прежнему закрывает проёмом-«проходом» — верно ли это для
фасада без окна, не проверялось. «Ждёт очереди» говорит «занят другим чертежом» и при
остановленном обработчике — вторая строка отправляет в «Состояние сервера».
