# DWG3D-11: Проекты: режим проекта и итог применения

## Цель

После смены этажа редактор выходит из режима проекта, и правки незаметно идут в настоящую
расстановку (а перенос связанного предмета в другое помещение проводит «Перемещение» в учёте).
Нужно, чтобы из режима проекта нельзя было выйти незаметно (ТЗ 5.3.6 п. 2, 6.5.2), «Открыть на
плане» вело туда, где проект правят, а итог применения проекта был виден (5.3.6 п. 7, 6.1 п. 5).
Находки ревью 21.10.2026: R-042 (З), R-043 (Н), R-007 (З). Подзадача DWG3D-1.

## Критерии готовности

- [ ] e2e С9 (`e2e/tests/stage8.spec.ts`) зелёный.
- [ ] Блок Б6 ручного прогона (`docs/review/MANUAL-RUN.md`) проходит.
- [ ] Из режима проекта нельзя выйти незаметно: переходы внутри редактора проект сохраняют, а
      если проект открыть нельзя — это видно, расстановка вместо него не открывается.
- [ ] Сценарий каждой находки покрыт тестом, который до исправления падал (R-033).
- [ ] CI зелёный.
- [ ] В `docs/review/FINDINGS.md` у R-042, R-043 — «исправлена» со ссылкой на MR; у R-007 —
      отметка о проверке.
- [ ] Справка (`web/src/help/content.ts`) и `docs/ADMIN.md` обновлены, если поменялось поведение.

## Решения и находки

<!-- ГГГГ-ММ-ДД — что решили и почему; что пробовали и отвергли. Архитектурное → ADR. -->

- 2026-10-28 — расхождение с задачей Plane: R-007 уже «исправлена» в !2 (DWG3D-2): итог в
  `ApplyDialog` сбрасывается только при открытии окна, тест `web/src/projects/ApplyDialog.test.tsx`.
  В этой задаче — только проверка.
- 2026-10-28 — R-043 «всегда 1-й этаж» точнее: `ProjectPage.tsx:103` уже берёт нижний этаж из
  `floor_ids` (этажи с изменениями, по `position`). Первый этаж открывается у проекта без
  изменений — как в Б6: «Новый проект» → сразу «Открыть на плане».
- 2026-10-28 — найдено по коду: переходы, теряющие проект, кроме выбора этажа:
  `EditorPage` (адрес без этажа → первый этаж без `?project=`), «+ этаж» (`FloorDialog.onDone`),
  проект не загрузился → обычный режим. Осознанный выход — «Как есть» в выборе проекта, меню
  слева, поиск — проект не сохраняет, и это нормально: полоса и рамка пропадают по действию
  человека.
- 2026-10-28 — 3D в режиме проекта: другие этажи (`View3D.tsx:50`) читаются из расстановки
  (`/api/floors/…/items`), а не из проекта — в виде «здание до этажа» изменения проекта на других
  этажах не видны. Из проекта это не выводит; решение — ниже.
- 2026-10-28 — решили с Yury Mikhailov:
  - R-043: проект без изменений открывается на последнем открытом в редакторе этаже здания
    (в браузере), иначе на первом надземном. Отвергли меню этажей у «Открыть на плане» — лишний
    щелчок при каждом открытии; «оставить первый этаж» — R-042 это смягчает, но Б6 начинается
    с поиска этажа.
  - «+ этаж» в режиме проекта скрыт, как «Строительство» и «Сохранить план»: проект меняет только
    расстановку, этаж добавился бы в настоящее здание.
  - 3D другие этажи в режиме проекта — чиним здесь (R-053): та же тема, правка небольшая.
  - ADR не нужен: публичный API и схема не меняются, выбор — в поведении интерфейса.
