# DWG3D-21: Перевод чертежей: масштаб, роли слоёв, тяжёлые листы

## Цель

Подзадача DWG3D-1 (исправления по ревью), находки R-057…R-060. Чертёж, начерченный не в
масштабе 1:1 и с графикой на слое «0», не переводится. Масштаб не определяется. Слой, в
названии которого есть «блок», принимается за стены. Часть с сотнями тысяч отрезков
переводится часами и упирается в предел памяти. На стенде разработки DWG не читается
(`APP_DWG2DXF` ведёт в несуществующий `legacy/.tools`).

## Критерии готовности

- [ ] Чертёж в масштабе листа (1:100, 1:500) разбирается в масштабе здания: масштаб
      определяется сам или берётся из заданного администратором (R-057).
- [ ] Слой, ошибочно принятый за стены, не отключает стены со слоя «0» (R-058).
- [ ] Часть с сотнями тысяч отрезков переводится за минуты в пределах памяти задачи; ход
      перевода меняется и внутри части (R-059).
- [ ] R-060 (решение Yury Mikhailov, 30.10.2026 — по минимуму): несуществующего пути
      `legacy/.tools` нет ни в `.claude/launch.json`, ни в `test_drawings.py`; `dwg2dxf`
      берётся из `APP_DWG2DXF` или `PATH`; в `docs/` одной строкой — где DWG читается.
- [ ] Итоги «Бастиона» и чертежей 7.2 не хуже прежних. Чертежей на машине нет, и сверять
      их решено без них (решение Yury Mikhailov, 30.10.2026): критерий остаётся
      непроверенным, это будет сказано в MR.
- [ ] Сценарий каждой находки покрыт тестом на синтетическом DXF, который до исправления
      падал; CI зелёный.
- [ ] В FINDINGS у R-057…R-060 — статус со ссылкой на MR; справка и `docs/` обновлены.

## План

<!-- Проверяемые шаги. Отмечайте выполненное, добавляйте найденное по ходу. -->

- [ ] 1. Тесты R-057…R-060 на синтетических DXF, которые строит сам тест; до исправления
      падают.
- [ ] 2. R-057, масштаб. Определяется по `DIMLFAC` большинства размеров пространства модели;
      администратор может задать масштаб, и тогда чертёж разбирается заново (столбец
      `drawing.scale`, миграция, `POST /api/drawings/{id}/scale`, ADR). Если самая большая
      часть меньше 10 м — предупреждение.
- [ ] 3. R-058, роли слоёв. Корень слова ищется с начала слова, а не в любом месте; «блок»
      из стен убран; латинские буквы, похожие на кириллицу, в смешанном слове становятся
      кириллицей; словари осей, размеров и прочих ролей пополнены английскими и немецкими
      словами. Если линий стен на части мало против «прочих» (слой «0»), в стены идут и они.
- [ ] 4. R-059, тяжёлая часть. Кандидаты в окна — только у обрывов стен; их число ограничено.
      Связные группы (`walls._components`) ищутся векторным запросом. Ход перевода
      показывается по этапам внутри части. После шагов 2–4 время и память перевода
      замеряются на тестовых чертежах вне репозитория.
- [ ] 5. R-060: `dwg2dxf` берётся из `APP_DWG2DXF` или `PATH`, без пути в `legacy/` по
      умолчанию (`server` и `worker` в `launch.json`, `test_drawings.py`). В `docs/` — одна
      строка: DWG читается только там, где есть LibreDWG, то есть в образе
      `deploy/Dockerfile` (0.14, как в установке); сборка conda-forge для Windows — 0.11, её не
      использовать. DWG-тесты 7.2 при нужде — в контейнере с LibreDWG из образа.
- [ ] 6. Интерфейс: в карточке чертежа — масштаб и откуда он взят, «Задать масштаб»,
      предупреждение о малом здании; справка, `npm run admin-guide`.
- [ ] 7. Проверка на одноразовом стенде (своя база и том, образ из ветки) на тестовых
      чертежах. После проверки база, том и образ удаляются. «Бастиона» и чертежей 7.2 нет:
      их не проверяем.
- [ ] 8. FINDINGS, ACCEPTANCE, проверки как в CI, MR.

## Решения и находки

<!-- ГГГГ-ММ-ДД — что решили и почему; что пробовали и отвергли. Архитектурное → ADR. -->

- 2026-10-30 — ручная проверка идёт на тестовых чертежах вне репозитория. Ни сами чертежи,
  ни данные из них в репозиторий, MR и Plane не попадают. В журнал пишется только «тестовые
  чертежи: проходит / не проходит, N с». Тесты — только на синтетических DXF.
- 2026-10-30 — масштаб определяется по размерам, а не по видовым экранам. Видовой экран
  листа показывает, во сколько раз лист меньше модели. Если чертёж начерчен сразу в
  масштабе листа, отношение 1:1, и масштаба здания экран не даёт. Множитель размеров
  `DIMLFAC` даёт именно его: размер показывает метры здания по отрезку в миллиметрах листа.
- 2026-10-30 — R-060 делается по минимуму (решение Yury Mikhailov). Тестовые чертежи — DXF,
  поэтому `dwg2dxf` на Windows не ставится. Сборка conda-forge для Windows — LibreDWG 0.11,
  а в установке 0.14: её не использовать.
