# Файлы задач

Один файл на задачу Plane: `ABC-123-kratko.md`. Это «память» задачи, которую может подхватить любой человек с любым агентом: цель, план, решения, журнал сессий и текущее состояние.

## Жизненный цикл

1. `pickup` создаёт файл из [`_template.md`](_template.md), ветку `ABC-123-kratko` и черновой MR.
2. Во время работы агент отмечает пункты плана и сразу записывает решения.
3. `handoff` в конце каждой сессии обновляет журнал и перезаписывает блок «Handoff».
4. `finish` ставит `status: done` и заменяет «Handoff» итогом.

Файлы не удаляются после завершения: это история того, как и почему делалась задача.

## Статусы

- `in-progress` — в работе;
- `blocked` — ждёт внешнего (причина в «Handoff»);
- `done` — передана на ревью или завершена.

Активные задачи — файлы, где `status` не `done`.
