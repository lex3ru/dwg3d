# Глоссарий

Термины предметной области и внутренний жаргон проекта. Агенты используют их в коде, тестах и документах — пишите так, как принято у заказчика и в коде.

| Термин | Значение | В коде |
| --- | --- | --- |
| Проведение | Документ учёта из черновика становится действующим: меняет места, состояния и остатки. Целиком или никак (ТЗ 5.4.4 п. 3) | `inventory.documents.post` |
| Обратный документ | Отмена проведённого документа: новый документ сегодняшним числом со ссылкой на исходный. Отменённый и обратный взаимно гасятся | `cancel`, `Document.cancels_id` |
| Событие единицы | Что стало с инвентарной единицей после документа или объединения помещений: место, состояние, оценка — на дату. Из событий строятся отчёты «на дату» | `UnitEvent`, `units.events_at` |
| Задним числом | Документ с датой раньше сегодняшней. Не раньше проведённой инвентаризации мест (5.4.4 п. 2); по единице — не раньше её последнего события, по количеству — без минуса на любую дату (ADR-0004) | `Posting.not_before_last_event`, `Posting.available` |
| Очередь учёта | Номера и остатки меняет один сеанс за раз: создание, проведение и отмена документов ждут друг друга (ADR-0003) | `inventory.documents.lock` |
| Позиция остатка | Остаток количественного учёта: место + тип + модель. «Без модели» — тоже позиция. Приход, расход, отчёт «Остатки» и пересчёт при инвентаризации — по позиции (ADR-0005) | `StockMove`, `CountStock`, `Posting._position` |
| Пересчёт | Фактическое количество позиции остатка, введённое при обходе. При проведении разница с учётом — строка «недостача» или «излишек» той же позиции | `counts.set_stock`, `post_count` |
| Очередь отметок | Метки, ручные отметки и пересчёт обхода, которые телефон ещё не отправил. Хранится в браузере, досылается сама; отметка уходит из неё, только когда сервер её принял или отказал по ней самой (6.7 п. 1) | `web/src/inventory/queue.ts` |
