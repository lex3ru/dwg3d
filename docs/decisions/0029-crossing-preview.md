# ADR-0029. Подтверждение перехода и проверка разметки
Дата 2026-11-04. Предложено. Дополняет ADR-0028.

На встречных траекториях временной фильтр прототипа отменял проходы разных людей.
При косом подходе к двери проверка положения уже после порога пропускала проход.

В режиме линии сопоставляем путь ног с отрезком порога между соседними наблюдениями.
После сглаживания два последовательных наблюдения за полосой порога подтверждают
сторону. Учитываем переходы отдельно для каждого трека. Обрыв трека не доказывает
проход. Контракт событий и существующая разметка сохраняются.

Для проверки администратор может запросить последний размеченный JPEG счётчика через
GET /api/surveillance/cameras/{id}/analytics/frame. Совмещение рамок с обычным RTSP-
просмотром давало бы смещение из-за разной задержки двух потоков. Возвращаем сам
кадр распознавания без записи на диск по запросу через локальный порт с токеном.
Проверяются доступ, включение, версии подключения и разметки, свежесть кадра.
Проверка предназначена для установки на одном хосте. Для удалённого счётчика
потребуется защищённый туннель. Полнота распознавания зависит от реальных траекторий.
