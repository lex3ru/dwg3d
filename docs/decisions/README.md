# Решения (ADR)

ADR — короткая запись одного решения: контекст, рассмотренные варианты, выбор, последствия. Пишется в момент решения навыком `adr` и попадает в репозиторий вместе с кодом.

**Когда писать:** выбрали библиотеку или фреймворк; поменяли схему данных или публичный API; выбрали протокол, формат или способ интеграции; сознательно пошли на компромисс («пока без кэша, потому что…»); отказались от очевидного пути.

**Когда не нужно:** решение видно из кода и не имеет разумных альтернатив.

**Статусы:** предложено → принято → заменено NNNN. Старые ADR не удаляются и не переписываются: решение меняется новым ADR.
