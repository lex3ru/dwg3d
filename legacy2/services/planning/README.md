# planning

Проектирование: варианты расстановки объектов здания (docs/TZ.md, 4.8). Маршруты людей, зоны, кабельные
трассы и расчёты (Wi-Fi, освещённость, извещатели, обзор камер) — позже.

Вариант хранит не копию объектов, а операции над фактом: поставить (`add`), переместить (`move`),
изменить (`change`), убрать (`remove`). Каждая операция над существующим объектом помнит версию объекта,
против которой сделана: если объект изменили в учёте после неё, операция конфликтует, а вариант
помечается «устарел» (по событиям `assets` и новой ревизии чертежа). Применение выполняет `assets` от
имени пользователя — с историей объектов; выполненное уходит из варианта, отклонённое остаётся с причиной.

Всё — администратору здания; факт и цены сервис берёт у `assets` и `catalog` с токеном пользователя
(своей учётной записи у сервиса нет). Без `planning` учёт, кабинет и редактор работают — без вариантов.

## Запросы

`/api/planning/v1` — `contracts/openapi/planning.v1.json`; описание — docs/CONTRACTS.md, раздел 9.

| Запрос | Что делает |
|---|---|
| `GET` / `POST /variants`, `GET` / `PATCH` / `DELETE /variants/{id}` | варианты |
| `POST /variants/{id}/edits` | правки из редактора |
| `GET /variants/{id}/view` | факт с наложенным вариантом |
| `GET /compare?building_id=&a=&b=`, `GET /variants/{id}/spec` | сравнение и спецификация с ценами |
| `POST /variants/{id}/apply` | применить |

## События

| Публикует | Когда |
|---|---|
| `planning.variant.created` / `.applied` / `.deleted` | вариант создан; применён (сколько выполнено и отклонено); удалён |

| Получает | Реакция |
|---|---|
| `assets.asset.*` | черновые варианты с операциями над объектом — «устарел» |
| `buildings.revision.published` | черновые варианты с объектами на изменённых этажах — «устарел» |

## Запуск и тесты

```bash
docker compose -f deploy/docker-compose.yml up -d db db-init nats
cd services/planning
uv run python -m twin_chassis.migrate && uv run uvicorn app.main:build --factory --port 8000
uv run ruff check . && uv run pytest
```

В тестах `access`, `assets` (объекты в памяти, с версиями) и `catalog` заменены заглушками.
