# Контракты

Единственный источник истины о том, как сервисы общаются. Описание для людей —
[docs/CONTRACTS.md](../docs/CONTRACTS.md).

| Каталог | Что в нём | Кто проверяет |
|---|---|---|
| `openapi/<сервис>.v1.json` | запросы сервиса | тест сервиса `test_contract`: запросы в коде и в файле совпадают |
| `events/envelope.json` | конверт любого события | `emit()` при каждой записи события |
| `events/<тип>.json` | поле `data` события этого типа | `emit()`: событие без контракта или не по контракту — ошибка |

Изменить запросы сервиса: поправить код, затем
`cd services/<сервис> && uv run python -m twin_chassis.contracts <сервис>` —
изменение файла и есть изменение контракта, оно проходит обычное рецензирование.

Изменить событие: только добавлением необязательных полей. Несовместимое
изменение — новый тип с суффиксом `.v2`, старый публикуется, пока у него есть
получатели.
