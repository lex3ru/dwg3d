# Цифровой двойник здания

Система ведёт цифровой двойник здания: само здание (этажи и помещения из
чертежа DWG/DXF), мебель и оборудование в нём, люди, которые в нём работают.
У пользователя — личный кабинет с объектами, к которым у него есть доступ;
администратор здания расставляет оборудование, ведёт его свойства и выдаёт права.

Новая версия строится из независимых сервисов. Сделаны этапы 0–3: каркас (общая
основа сервисов, шлюз со входом через Keycloak, шина событий, шаблон сервиса, стек в
Docker Compose) и здание из чертежа — DWG/DXF становится зданием с этажами и
помещениями, которое открывается в 3D и 2D; справочник людей и права по областям
(здание, этаж, помещение); каталог типов оборудования со схемами свойств. Что именно
проверено — в
[docs/ACCEPTANCE.md](docs/ACCEPTANCE.md).

## Структура репозитория

| Каталог | Что в нём |
|---|---|
| `services/` | сервисы: `gateway` (шлюз), `import` (чертежи и сборки), `buildings` (здания, этажи, помещения), `people` (люди), `access` (права), `catalog` (каталог), `ping` (образец), `_template` (шаблон нового сервиса) |
| `libs/chassis/` | общая основа сервисов: токены, ошибки, события, журнал, миграции |
| `contracts/` | контракты: запросы сервисов (OpenAPI) и события (JSON Schema) |
| `frontend/` | интерфейс |
| `deploy/` | Docker Compose, Keycloak, резервные копии |
| `e2e/` | сквозные сценарии этапов в браузере |
| `tools/` | `new-service` — создать сервис из шаблона |
| `docs/` | документы новой версии |
| `legacy/` | текущая версия — одно приложение «DWG → 3D» ([описание](legacy/README.md)) |

## Запуск

```bash
cp deploy/.env.example deploy/.env
docker compose -f deploy/docker-compose.yml up -d --build
```

Откройте http://localhost:8090 (первый вход — `admin` / `admin`). Подробности и запуск на
сервере — в [deploy/README.md](deploy/README.md).

## Разработка

Сервис проверяется без соседей — нужны только PostgreSQL и NATS стека:

```bash
docker compose -f deploy/docker-compose.yml up -d db db-init nats s3
cd services/ping && uv run ruff check . && uv run pytest
```

Сквозные сценарии — на запущенном стеке:

```bash
cd e2e && npm ci && npm run browsers && npm test
```

Новый сервис: `tools/new-service <имя> "Название"` — рабочий сервис с образцом
сущности, тестами и контрактами, вписанный в Compose, шлюз и CI.

Правила, общие для всех сервисов, — в [docs/CONTRACTS.md](docs/CONTRACTS.md), раздел 1;
их реализация — [libs/chassis](libs/chassis/README.md).

## Текущая версия

Лежит в `legacy/` целиком: код, Docker Compose, свои документы. Она остаётся
рабочей до приёмки новой версии: по ней сверяются разбор чертежей и расчёты,
из неё переносятся конвейер DWG → 3D и просмотрщик. Состояние до разделения
на сервисы отмечено тегом `v1-monolith`.

Все команды текущей версии выполняются из `legacy/`:

```bash
cd legacy
docker compose up -d --build     # весь стек; подробности — legacy/docs/DOCKER.md
```

Локальные данные (`legacy/.env`, `legacy/data/`, `legacy/.tools/`, чертежи
`*.dwg`) в репозиторий не входят.
